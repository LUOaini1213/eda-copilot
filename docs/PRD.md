# EDA Copilot 一页 PRD

## 问题
EDA 流程问答里，**问题看起来有答案、其实缺了决定答案的前提**。
猜 setup/hold 会给出方向相反的建议；猜 WNS/TNS 会指向完全不同的修复动作；
问「我这次跑的结果」而系统没有运行数据时，它会拿文档当结果。

## 用户与场景
后端工程师 / 新人：问流程里某个命令、参数、阶段依赖是什么。
**不是**用来替代 STA 工具，也**不是**用来读某次具体 run 的结果。

## 范围
**做：**在 OpenROAD/ORFS 的脚本与模块文档上，回答「这是什么、怎么用、为什么这么排」。
**不做：**不产生数值结论、不解读用户自己的 run、不覆盖 DRAM 器件与工艺。

## 验收标准（全部可判定，不用形容词）
1. 检索：20 条标注题上 **Hit@5 ≥ 0.90**，且每条回答必须带**可定位到文件+行号/章节**的出处。
2. 停问：10 条该停的题 **100% 停住**，且 **原因码判对率 100%**。
3. 消融：关掉护栏后，该停的题**全部**变成强行作答，且**对正常问答零回归**——
   证明护栏只拦该拦的，不误伤。
4. 误伤：文档/定义类问题**不得**被面向结果的护栏拦下。
5. 组件必要性：任何一个额外组件（如混合检索）必须在评测上拿出增益，否则**不进默认路径**。
6. 离线：不接大模型、不读任何 API key，系统完整可用，零 token、零费用。
